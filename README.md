# 💰 Smart Expense Tracker

## 📌 About Project

Smart Expense Tracker is a Flask-based web application that helps users manage their income, expenses, monthly budget, savings goals, and financial reports.

---

## 🚀 Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Bootstrap 5
- Chart.js
- ReportLab

---

## ✨ Features

- 🔐 Secure Login & Registration
- 💰 Income Management
- 💸 Expense Management
- 📅 Monthly Budget Management
- 🎯 Savings Goal Tracking
- 🔍 Expense Search
- 📆 Date Filter
- 📊 Expense Distribution Chart
- 📈 Monthly Expense Report
- 📄 PDF Report Download
- 🌙 Dark Mode
- 👤 User Profile
- 🔔 Flash Messages
