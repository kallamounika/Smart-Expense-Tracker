💰 Smart Expense Tracker

📌 About Project

Smart Expense Tracker is a web application that helps users manage their daily income, expenses, monthly budget, savings goals, and financial reports.

🚀 Technologies Used

  • Python
  • Flask
  • MySQL
  • HTML
  • CSS
  • Bootstrap 5
  • Chart.js

✨ Features

  • Secure Login & Registration
  • Income Management
  • Expense Management
  • Monthly Budget
  • Savings Goal Tracking
  • Expense Search & Date Filter
  • Expense Charts
  • PDF Report Download
  • Dark Mode
  • User Profile
  • Flash Messages
